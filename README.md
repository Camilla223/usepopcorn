# 🍿 usePopcorn

A simple React app that lets you browse movies fetched from the [OMDb API](https://www.omdbapi.com/) and create your own **“Watched List”** with personal ratings.  
This project demonstrates key React concepts like controlled components, conditional rendering, lifting state up, and the use of React Hooks (`useState`, `useEffect`, `useRef`).

---

## 🚀 Features

- 🔍 Search for movies via the OMDb API  
- 🎬  View detailed movie information   
- ⭐ Add movies to your personal “Watched List”  
- 💬 Rate movies using controlled input components  
- 🗑️ Remove movies from the watched list  
- 💾 Persist watched movies using local storage  
- ⚡ Manage state and side effects using React Hooks  
---

## 🛠️ Built With

- **React** – UI library  
- **JavaScript (ES6+)** – For modern syntax and logic  
- **OMDb API** – For fetching real movie data
